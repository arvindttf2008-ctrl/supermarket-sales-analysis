# Supermarket Sales Analysis

## Project Overview
This project analyzes supermarket sales data using Microsoft Excel.

## Key Features
- Total revenue analysis
- Total orders and average order value
- Product-wise sales analysis
- Category-wise sales analysis
- Payment mode distribution
- KPI calculations
- Excel dashboard with charts

## Tools Used
- Microsoft Excel
- SUM, AVERAGE, MAX and MIN
- COUNTIF and SUMIF
- Data Visualization
- Dashboard Development

## Dataset
Contains 20 fictional supermarket sales records for learning and portfolio practice.

## Objective
To analyze sales performance and present useful business insights through an Excel dashboard.
